# Heart Rate Monitor

This is a very simple Android app to measure your heart rate, using your phone's heart rate sensor. Optionally, it can also save measurements to an internal database.

I mainly made this app because I wanted to get readings from the sensor without using Samsung Health. It should work with all phones that have an integrated heart rate sensor like the Samsung Galaxy S7, S8, S9, S10 and more.

This app is **unmaintained**, as I sadly no longer use a phone with a heart rate sensor. It is a very basic app, so it should still work fine for a long time.
